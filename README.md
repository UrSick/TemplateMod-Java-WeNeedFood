# RouteRecorder
# Сделан на основе JouTak Mod Template (Java Edition) в качестве тестового задания

**Minecraft 26.1.2**, **Fabric** и **Java 25**.

Мод создаёт вейпоинты в виде стрелочек в месте, где прошёл игрок.
По умолчанию запись включается и выключается на кнопку C, запись можно поставить на паузу с помощью кнопки V.
В планах сделать функционал для автоматического прохода игрока по точкам в обратную сторону.

Мод имеет необязательную интеграцию с LambDynamicLights

> [!NOTE]
> (https://modrinth.com/mod/lambdynamiclights)
